# 人体内非创伤性异物影像检查和评估专家共识 · 核心提炼

> 来源：中华放射学杂志 2026, 60(1): 24-35
> 作者：中国医疗保健国际交流促进会影像医学分会 等
> 通信作者：鲜军舫、肖喜刚

## 一、核心要点

- 异物误吞/误吸等进入自然腔道（鼻腔、外耳道、咽-食管、气管-支气管、胃肠道、尿道、阴道），误漏诊可危及生命
- 共识提出 **13条推荐意见**（GRADE分级：证据A～D，推荐强/弱）
- 气管-支气管异物已高居1岁以内儿童意外死亡原因第三位

## 二、各部位检查方法首选（速查表）

| 部位 | 首选检查 | 关键补充 |
|---|---|---|
| 鼻腔/外耳道 | 直视/内镜（90%+可直视取出） | 异物过大、位置深、疑肉芽肿包裹或需评估邻近结构 → **CT平扫+MPR** |
| 咽-食管 | 成人：**CT平扫**（灵敏度和阴性预测值100%） | 儿童：先**X线平片**（98%为高密度异物），阴性仍高度怀疑→CT；**不推荐食管造影**（假阴性40%，对比剂掩盖异物、有误吸风险） |
| 气管-支气管 | **CT平扫+MPR+仿真支气管镜**（灵敏度90%～100%） | 儿童植物类异物占70%～80%；右侧支气管多于左侧 |
| 胃肠道 | 金属/高密度：**腹部X线平片**筛查随访 | X线阴性或疑穿孔/脓肿/瘘 → **CT平扫**（灵敏度100%，特异度91%）；儿童推荐**高频超声** |
| 尿道/阴道 | 高密度/大/尖锐异物 → **CT平扫** | 可透X线异物、已入膀胱 → **超声**（灵敏度约80%）；儿童视诊阴性→超声 |
| 体内藏毒 | **低剂量CT平扫**（检出率提高30%，灵敏度和特异度均100%） | 典型表现：类圆形高密度团块+包膜影+"气环征" |

## 三、关键评估要点

### 1. 食管异物
- 测异物距门齿距离：**术中距离 = 3.078 + 0.13×BMI + 0.875×CT图像硬腭距离**
- 长径>22 mm 尖锐异物 90% 致穿孔（枣核、鱼刺最常见）
- 嵌顿部位：食管起始处（约15 cm）、跨左主支气管处（约25 cm）、食管裂孔处（约40 cm）

### 2. 并发症征象
- 纵隔积气 = 食管穿孔可靠征象
- 食管周围炎：壁肿胀+气体密度影+片絮状渗出
- 食管周围脓肿：纵隔内低密度团块，可伴气液平面
- 支气管异物：阻塞性肺气肿、肺不张、气胸/纵隔气肿

### 3. 胃肠道高风险异物
- 纽扣电池：>2 cm 或 48h 仍滞留胃内 → 内镜取出；X线呈双环状/条状高密度影
- **磁性异物**：多块相互吸引可致肠壁坏死，取出后仍需影像随访
- 钝性异物 >6 cm 易卡十二指肠袢（Treitz韧带附近穿孔）
- 尖锐异物（鱼刺/枣核/牙签等）并发症率15%～35%

## 四、随访建议

| 情况 | 处理 |
|---|---|
| 取出后无症状 + 黏膜完整 | 无需影像随访 |
| 腐蚀性异物（电池）术后 | 抗感染治疗开始后 3～7 天 MRI 复查（先排除铁磁性残留） |
| 高风险异物/穿孔术后 | 3～7 天 CT 随访对比；儿童用超声 |
| 食管穿孔术后留置胃管 | 术后 7～10 天复查食管 CT，评估后决定拔管 |

## 五、检查注意事项

- 未明确诊断前胃肠道 CT 平扫**不推荐饮水/口服对比剂**（防外溢加重腹膜炎）；拟手术者可用稀释碘对比剂（300～320 mg/ml 按1:6、350～400 mg/ml 按1:8稀释）
- 重组图像层间距 ≤ 层厚；小异物结合源图像观察
- MRI 前须排除铁磁性异物残留，防二次损伤
